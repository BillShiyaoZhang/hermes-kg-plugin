# Web 工作台 P0 实施与验收记录

更新日期：2026-10-23。依据：[产品 UI/UX 设计](product-ui-ux-design.md)。

本轮把五个一级区域的 P0 交互、故障恢复、隐私和可访问性基础统一到同一工作台。下面逐项区分浏览器实测、自动测试、代码审查及未验收条件，不以构建成功或自动扫描结果替代完整 UI/UX 验收。

用户已确认本轮暂不具备其他平台和屏幕阅读器的实测条件，本轮按当前可用环境交付。**Windows NVDA、macOS VoiceOver、WebKit / Firefox 桌面和实际窄屏触控仍是正式发布前的 P0 验收门槛**；这不是降低优先级，也不代表已通过无障碍认证。

## 环境和数据边界

- 浏览器写入验收使用独立合成 profile、真实 Neo4j 业务数据及受控故障夹具；不对私人记忆做试写。
- 正常查询、详情、纠正、停用/恢复、审阅及回填使用真实产品路由。故障夹具仅控制延迟、凭据失效、响应丢失、部分回执和不可用状态。
- 同步执行/模型解释的浏览器夹具使用受控替身验证 UI 与请求边界，不调用外部模型。真实模型和宿主集成的独立证据见 [真实模型验证](real-model-validation.md)，不能把两类测试互相代替。
- 本轮浏览器环境为 Windows 当前 Chromium 表面。窄屏和 200% 文字由独立私有同源验收页提供 CSS 视口与字体条件；产品仍保留禁止嵌入的安全策略。
- 原始日志、合成 profile、配置、部署备份、轮询与请求计数留在 Git 忽略的本地报告目录。产品代码、文档和发布包不包含私人会话、真实凭据、本机路径或固定个人身份。

## 自动无障碍检查与未决项

五区 320、1280、320 + 200% 文字的修复前检查记录均为 `violations=[]`；人工复核仍从 incomplete 中发现头像/审阅数量对比及关系数量 ARIA 缺陷，已修复。**因此 violations=[] 本身不是“无缺陷”的证明。** 最终构建的知识结构 320 复扫记录 `axe-ontology-final-320.json` 仍为 `violations=[]`，已无 aria-prohibited 未决项；剩余 8 个 color-contrast 未决节点按下表人工分析，不能当作自动认证通过。

| 未决项/发现 | 判断和证据 |
| --- | --- |
| 关系数量 span 的 aria-label | 真实语义缺陷，已改可读数量文本，保留未知数量说明；最终知识结构 320 复扫已无 aria-prohibited 未决项。 |
| 单字头像 M | 工具因单字无法判读；原对比 3.27。现 `#22332b` / `#e7e9df` 为 10.86:1，并有可访问名称“设置与诊断”。 |
| 审阅单字数量 | 原对比 2.06 且 8px；现至少 12px，`#58675f` / `#eff3e6` 为 5.29:1。 |
| 主导航局部裁切 | 水平滚动导航导致工具不能确定部分标签背景；源样式普通/选中/悬停分别 6.37/7.65/5.92:1。键盘滚入和焦点完整性需结合人工操作核对；导航已改为内部焦点轮廓避免裁边。 |
| SVG 标签与节点矩形叠层 | 工具不解析部分底层图形或裁切。边文字 7.64、节点名称 12.57、计数 5.63（选中底色 5.21），未降低透明度；关系表提供文字等价入口。色比合格不等于证明每个图形状态绝无遮挡。 |
| 同步渐变背景 | 较暗端保守计算：辅助标题 5.49、正文 5.54、主标题 12.37；另一端更浅。工具未决来自渐变，不是测出的对比失败。 |

色比依据当前源样式和 sRGB 相对亮度公式。它用于补充自动未决项，不代替实际级联、遮挡及屏幕阅读器的任务验证。原始自动报告、操作记录和构建证据位于 Git 忽略的本地 `reports/web-p0/`。

最终桌面知识结构复扫同样没有自动违规，也没有无效 ARIA 未决项。已人工查看默认人物关系图的箭头、名称和计数，当前状态未见相互遮挡；这不代表所有可选图状态均已逐个验证。窄屏主导航可通过键盘将设置入口带入并聚焦，采用内描边防止焦点边界被横向容器裁掉。最终记忆库和关系图的合成数据截图保存在本地报告中。

验收结束后，临时浏览器标签和服务已关闭。四个合成 profile 对应的八个命名空间在持久备份和越界关系检查后清理，确认无残留；清理只连接独立验证库。正式记忆服务仍正常响应。本机业务图和配置的备份继续保留，未上传 Git。

## 已发现并修复的问题

- 旧弹窗 effect 重跑会把后来的认证弹窗设 inert；改稳定关闭引用及正确的背景范围，嵌套重新认证实际通过。
- 回填在失连/401 时丢选中会话、刷新时抹掉部分回执警告；分别保留选择并拆开元数据/操作错误，故障流程通过。
- 历史回填真实路由暴露错误；已修并增加回归，真实 2 会话入队通过。
- 任务轮询可能重叠回退旧状态；改串行轮询与离页取消。
- 冲突 rebase 会把没改过的旧字段当作新修改；改仅保留实际编辑字段，另有单测。
- 偏好专属字段原先不可更正；增加真实 key/value 编辑并验证落库与生命周期。
- 勾选解释开关会立即重发旧查询；改为搜索提交时捕获模式，受控计数验证通过。
- 辅助文字、头像、审阅数量、分页/侧栏小字以及无效数量 ARIA；已修颜色、尺寸或文本语义，并保留最终复扫结果。

## 正式发布前的验收门槛与限制

1. Windows NVDA + Chromium 与 macOS VoiceOver + Safari 的完整找回、核对、纠正和故障恢复任务。
2. WebKit、Firefox 桌面及至少一个实际窄屏触控环境；记录具体版本和结果。
3. 原生 400% 浏览器缩放、系统强制颜色/减少动态效果与更大桌面视口的专项记录；CSS 重排和 200% 文字不能冒充这些条件。
4. 扩大到各类编辑/认证/维护长等待和所有错误状态组合；本轮只报告代表路径与共享组件/API 单测覆盖。
5. 用户研究和 persona 验证、10,000 实体容量目标仍是设计中的研究/P1 项，不作为本轮工程验证已完成的内容。

本轮可按用户确认的可用环境交付已列明的实现和验证结果；正式发布门槛保持清晰、可追踪，不宣称所有平台、所有情境或无障碍认证通过。
