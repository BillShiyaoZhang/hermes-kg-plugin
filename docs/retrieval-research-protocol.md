# 图结构知识检索研究协议 v1

协议冻结日期：2026-10-24。先冻结数据划分、指标与晋级门槛，再查看盲测结果。
这是实验协议；未完成的实验、人工标注和平台验证不能写成已经通过。

## 目标与边界

CPU 默认、GPU 可选；在已记录硬件上，暖机完整 HTTP 检索 p95 ≤3000 ms，
不计生成回答。真实样本和 gold 只保存在忽略的 `reports/`，不提交源码仓库。
默认模型是否替换取决于正式盲测；合成实验、模型排行榜或模型自评不能授权切换。
本轮不改变 MiniMax 抽取模型，不自动合并实体或发布本体，不执行任意 Text-to-Cypher。

## 数据与划分

事实集 300 题：200 合成（60 dev、140 blind）加 100 真实（40 dev、60 blind）。
真实题先由当前 profile 的只读快照生成候选，再人工检查问题、充分证据与不可回答性。
生产快照并不自动等于纯真实业务数据，历史测试记录应识别并排除。
本体集另列 60 题（20 dev、40 blind），定义命中不计作事实命中。
另列至少 120 项权限、归档、版本、方向、定义/事实区分和更新边界测试。
既有 search_50 仅回归，不作新盲测。按来源事实/会话/改写家族分组，禁止家族跨 split。
约 20% 的事实题为真正无答案；相关性为 0 无关、1 背景、2 足以支持答案。
未人工复核的题不作为 gold。数据锁定应记录内容指纹、审阅人声明和协议版本。

## 分阶段实验

1. E5-small 与 Qwen3-0.6B × values/entity/entity_relations 六组，使用精确 cosine，
   关闭关键词、图扩展、重排。实体与关系卡保留真实来源，规则独立检索。
2. 最多两种表示入围，扩展到 E5-base、BGE-M3 dense 和可合法访问的 EmbeddingGemma300M。
   固定原生维度及官方任务格式，首轮不混入降维、量化或 BGE 多检索头。
3. 固定模型/表示，比较 exact 与 Neo4j ANN；比较无向量、纯向量、混合、混合+有向图查询。
   所有组使用同样的唯一证据与上下文预算，max-chunk 合并，不能靠重复卡片增加投票。
4. 仅开发集 Recall@50 ≥95% 且 Precision@5 <80% 时增加 Qwen3-Reranker-0.6B，重排前30条。
5. 冻结入围配置，盲测当前流程、新流程E5、新流程候选模型，不在盲测后继续调参。

所有配置记录权重完整 commit SHA、文件 SHA256、编码/池化/前缀、依赖锁、设备、线程、
批量与输入预算。先 prepare 后固定 fingerprint；指纹不同的向量不能混在同一缓存或索引。
不满足许可或下载条件的模型明确记为 unavailable，不能用替身模型或随机向量代替。

## 指标与晋级

- 主指标 nDCG@10；辅助 Recall@20/50、MRR@10、P@5、充分证据集合召回及分组结果。
- 新流程相对现流程 nDCG@10 至少提高0.03，成对差值95%区间下界>0；关键分组
  Recall@5 不下降超过0.03。更重模型还须与同一流程E5比较，收益不明确时保留轻量默认。
- 按来源/问题家族做成对 cluster bootstrap；报告预定义比较的 Holm 校正与样本量。
- ANN Top50 对预过滤 exact 参照的一致召回≥98%；后过滤不足、重复chunk和跨空间竞争单列。
- 无答案误注入率≤5%，可回答题充分证据覆盖≥90%；阈值仅由dev校准，cosine/RRF不是概率。
- 权限、归档、旧正文泄漏及规则冒充事实为零；观察零错误仍报告样本量及不确定性。
- 1k/10k实体、真实计算向量、真实关系分布；CPU统一8线程，单请求p95≤3s；并发4、GPU、
  冷启动、RSS/VRAM、全量/增量索引与更新可见延迟分别报告。契约假向量测试不算语义实验。

端到端预选15真实+15合成任务，原/候选流程各两次，最多120次已配置MiniMax调用。
固定生成配置，人工判断答案与证据；原始盲测题与输出仍留在本地私有报告目录。

## 更新及发布

投影版本、模型版本和索引代隔离。一次请求固定一代，构建并追平写入后才原子切换。
实体/关系/端点改名、本体标签、权限、归档及恢复应使相关投影失效；最终读取核验当前权威数据。
新卡未就绪不得返回旧正文或把未索引误报无数据。保留已有本体停用后的历史读取语义。
初步工具与报告可以交付；正式默认切换必须等待真实gold、盲测、安全及性能门槛均通过。

当前实机：Windows，Intel Core i7-12700，64GB RAM，RTX3070Ti 8GB。
实测时补充OS/Python/驱动、资源限制、热身与重复次数，不把本机结果泛化到未测平台。
