# 统一知识图谱工作区：实施与验收记录

更新日期：2026-10-23。设计依据：[产品 UI/UX 设计 v2](product-ui-ux-design.md)。

本轮将原“记忆库”“知识结构”“审阅收件箱”的内容集中到单一“知识图谱”工作区：类型定义、已保存实体/关系和待审候选共用一张交互图、一组筛选和一个上下文详情，另有等价列表。目标是集中查找、关联理解和审阅，而不是创建第四个重复入口。

**本轮统一图谱功能已交付并更新到现有本机服务，发布包、运行读验和合成夹具清理均已完成。** 最终 324 项 Python（0 跳过）与 92 项前端测试通过。114 批夹具覆盖跨百批搜索、聚焦、批准及只读 HTTP 验证，重排、字面文本、长等待、旧响应保护和失连禁写也有实际记录。人工审查发现的列表命名语义问题已修复并复扫；零自动违规仍不构成无障碍认证。未逐组合重演与正式发布前环境门槛分别列明，不能将它们误读为已知功能缺陷或全部验收已完成。前轮证据见 [历史 P0 验收](web-p0-validation.md)，不直接替代本轮新增图谱验收。

## 语义与范围

- “记忆库”和原“知识结构 → 实际数据”来自同一业务知识库；旧页面的生命周期、检索方式和命名空间范围不同。合并界面后仍须说明这些范围。
- 类型定义表示允许的结构，已保存表示入库知识，待审表示尚未应用的提案。类型颜色一致；图层身份另用文字、形状或线型区分，不仅依赖颜色。
- 当前有效图只包含当前命名空间有效业务实体及两端均可见的关系；归档和获准的外部共享只读详情不混入该图的计数。隔离、系统、回执、历史等内部记录不成为业务节点。
- 同 URI 的候选和已保存版本有独立选择身份。候选关系能追溯审阅批次，只有服务确认已应用后才能作为已保存事实出现。
- 有限画布显示加载/截断边界；已保存内容的当前空间搜索和一跳聚焦不局限最初子图。类型聚焦从全空间读取该类实例；定义关系、候选和批次聚焦只针对已加载图，标签说明边界。候选搜索已改为服务端全待审批次过滤、计数后分页，不再局限预取集合。未加载、被隐藏、范围不可见、无匹配和真正为零分别说明。

## 环境、隐私与证据规则

- 写入和故障验收只使用独立合成 profile、受控候选和隔离数据库；不对私人记忆试写，不把本机配置、实际凭证或私人事实写入 Git。
- 修改本机部署前保留原数据、程序与配置的必要备份；部署后用只读核对确认数据与配置边界。具体路径、端口、摘要原值和原始报告只留本地忽略目录。
- 图形不依赖上传式第三方渲染；搜索词、记忆 URI 和令牌不进入地址栏/历史。外部模型解释默认关闭，只有明确提交搜索才使用所选模式。
- 自动测试、构建、浏览器操作、自动无障碍扫描和人工视觉核对分别记录；任一单项不能代替其他证据。
- 用户已确认暂无额外平台：Windows NVDA、macOS VoiceOver、WebKit、Firefox 和真实触屏仍为正式发布前的 P0 门槛。当前 Chromium 与 CSS 窄屏结果不能代称这些环境通过。
