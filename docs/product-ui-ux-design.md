# 个人知识与记忆工作台：产品与 UI/UX 设计

版本：设计基线 v3.2（增加本体 CRUD 与风险分级），2026-10-24。适用对象：自托管、单工作空间的 Web 工作台。

本文把设计要求、已取得的证据及后续规划分开。v3 以知识探索和核对为主，在同一工作区提供“本体 / 探索 / 审阅”三个视角，采用浅色克制画布、自适应全图和可恢复的探索上下文。探索证据以 [v3 验证记录](graph-v3-validation.md) 为准，本体 CRUD 证据另见 [CRUD 验收](ontology-crud-validation.md)；设计要求不等于全部交互已经验收。

历史：v2 合并了三个分离数据入口，其 324 项 Python、92 项前端及部署证据见 [统一图谱验收](unified-graph-validation.md)；v1 见 [知识结构专项](ontology-ui-validation.md) 与 [完整 Web P0](web-p0-validation.md)。旧界面的浏览器、打包或部署结果不自动转移到 v3。运行与模型证据见 [真实模型与引擎验证](real-model-validation.md)。本轮不据历史记录宣称已经部署、完成用户研究、通过辅助技术或取得无障碍认证。

## 1. 产品目标与设计边界

工作台帮助知识所有者回答四个问题：“记住了什么？”“为什么这样记？”“它与什么有关？”“怎样修正？”主路径是找回、核对、修正和追溯；运行维护为次级路径。成功不以图谱节点数量或动画丰富程度衡量，而以人能否理解、信任并控制自己的记忆衡量。

本次核心交付是一个图谱工作区：本体视角解释规则，探索视角呈现实际知识，审阅视角核对候选与已有事实。三个视角复用画布能力与唯一上下文检查器，各自保存筛选、布局和位置。图形提供空间线索，等价列表支持精确扫描与键盘任务；默认不把本体规则、实际关系和待审提案挤在同一张图中。

“记忆库”和原“知识结构 → 实际数据”读取的是同一业务知识库，原先只是范围和表现不同：前者支持生命周期与检索模式，后者限制在当前空间的有效实体及内部关系。合并不意味着取消这些边界。工作区分别说明当前数据范围、搜索范围与图中已加载范围，避免把有限画布误称为整个记忆库。

产品名称、导航、空状态使用中性领域语言。具体宿主、数据库、模型和调度器出现在集成设置或诊断中。单工作空间是当前部署边界；“维护者”是使用情境，不代表已经存在账号、角色或权限管理。

本体检查器与管理目录支持当前空间类型、属性和关系的创建、编辑、停用、恢复及受约束删除；范围与风险交互见 5.6、5.7 节。本次不包含修改已发布存储标识、图形化改边、跨工作空间聚合、团队授权和托管云账号系统。既有可见性、归档、共享只读和隔离规则同样约束知识结构。

## 2. 设计依据：把 Apple 原则转为 Web 行为

以下为 Apple 官方 HIG 的产品化映射。右列是本项目的设计选择；不是 Apple 对此类知识产品的直接规定，也不要求复制 macOS 外观、原生材质或控件。

| 官方原则与来源 | 本项目的具体映射 | 可检查的结果 |
| --- | --- | --- |
| 按重要性组织内容，分组并逐步展开。[Layout](https://developer.apple.com/design/human-interface-guidelines/layout) | 一个图谱工作区承载查找和审阅；图层与类型筛选集中，详情仅在一个上下文检查区展开。 | 名称、证据、写入操作各有主要位置；首次进入能辨别“定义 / 已保存 / 待审”。 |
| 侧栏承载主要区域，分组清楚，适应小屏。[Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars) | 三个一级入口：知识图谱、同步与任务、设置与诊断；窄屏保留有文字的可达导航。 | 不再要求用户在三个数据入口之间来回切换；当前区域始终有文字和选中态。 |
| 反馈应说明结果，并与影响程度相称。[Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback) | 筛选在原位反馈；长任务显示排队/运行/完成；冲突保留草稿并解释下一步。 | 请求已接收不显示成“已保存”；普通查询不触发阻塞弹窗。 |
| 列表、表格与图表应依据信息任务选择；渐进显示细节。[Charting data](https://developer.apple.com/design/human-interface-guidelines/charting-data) | 节点图突出连接；等价列表承载精确扫描、归档和检索结果；两者复用选择与详情。 | 不需要拖动画布才能找到记忆；切换视图不产生第二份独立筛选和详情。 |
| 数据应突出，并有足够上下文。[Charts](https://developer.apple.com/design/human-interface-guidelines/charts) | 数量标明范围、生命周期和时点；布局位置不暗示关系强度，线条不暗示模型置信度。 | 定义数量与实例数量有不同标签；未获取到数量时显示“暂不可用”，不显示 0。 |
| 信息不能只靠颜色；文字、对比与辅助技术均需支持。[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) | 类型有一致颜色和名称；定义、已存与候选另以形状、边框及文字区分；图和详情具有语义化替代入口。 | 候选不只因颜色不同而被区分；键盘和屏幕阅读器有完整任务替代路径。 |
| 文字层级要清晰，放大后仍保留内容顺序。[Typography](https://developer.apple.com/design/human-interface-guidelines/typography) | 系统字体栈、有限字号层级、可换行标题；放大时由双栏变单栏。 | 200% 文字放大后主行动不被遮挡，正文不会只能通过悬停读全。 |
| 颜色用于传达层级和状态，兼顾可读性。[Color](https://developer.apple.com/design/human-interface-guidelines/color) | 使用语义 token；类型色与成功/警告/错误色分离。 | 同一状态跨页面使用同一图标、文案与颜色；选中态具有轮廓或背景差异。 |
| 仅在确实知道进度时显示确定进度。[Progress indicators](https://developer.apple.com/design/human-interface-guidelines/progress-indicators) | 查询用等待状态；索引显示实际处理量，未知总量仅显示阶段。 | 不编造百分比或剩余时间；长任务可离开页面后继续查看。 |
| 警告用于必要且可行动的问题。[Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts) | 失连、空结果和普通错误原位展示；不可逆动作才使用明确的确认。 | 网络启动失败不弹反复阻塞对话框；按钮写“重新连接”“保留草稿”，不用“是/否”。 |
| 最少必要数据、透明用途，尽量本地处理。[Privacy](https://developer.apple.com/design/human-interface-guidelines/privacy) | 本地搜索默认；外部模型解释显式开启；图形不接入第三方上传式渲染服务。 | 查询前可看出是否会发送给已配置模型；错误和诊断不展示令牌、连接密码或完整配置。 |

Web 的可测无障碍目标采用 [WCAG 2.2](https://www.w3.org/TR/WCAG22/)，包括对比、重排、键盘、焦点和状态消息。具体对话框遵循 [WAI-ARIA APG Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。本文的 CSS 像素、断点和测试门槛是项目选择，不把 Apple 原生平台的点值直接等同于 Web 像素。

## 3. 用户假设与待验证问题

下面的 persona 由产品用途与现有能力推导，**未经访谈验证**，不能当作真实用户统计。

| 假设 persona | 目标与情境 | 当前阻力假设 | 设计响应与待验证点 |
| --- | --- | --- | --- |
| 主：知识所有者 | 偶尔回看多年记忆，核对某个偏好、决定或事件；不熟悉图数据库。 | 不确定搜索无结果是没记录、没索引还是措辞不同；担心错误被持续使用。 | 解释搜索模式与范围；详情展示证据、关系、历史及修正入口。访谈确认用户是否理解“归档”和“纠正”的区别。 |
| 次：工作台维护者 | 由本人或受托人员维护服务、同步和模型；希望故障定位快且不误改数据。 | 数据状态、抽取状态与索引状态混淆；技术日志包含敏感信息。 | 分开连接/同步/检索状态；任务记录给下一步操作，诊断默认脱敏。验证他们实际需要哪些指标。 |

共同假设：用户会在桌面做核对和编辑，在手机做快速查找；知识内容可能私密；用户可理解自然语言类型名称，但不应被要求理解 URI、OWL 或调度命令。后续研究若不支持这些假设，应调整优先级而不是只润色文案。

| 用例 | 用户行动 | 主要区域 | 完成标准 |

| U-06 补齐与维护 | 看同步、暂停/恢复、选择历史会话回填 | 同步与任务 | 队列、运行和结果可区分；离页不丢任务状态。 |
| U-07 安全接入与诊断 | 输入令牌、看健康、准备本地检索、退出连接 | 设置与诊断 | 明确连接边界和数据去向；敏感值默认不展示。 |

## 5. 统一“知识图谱”工作区规格

### 5.1 概念与数据口径

“实体类型”解释允许记录什么；“关系定义”解释可以怎样连接；“已保存”才是当前工作空间中已入库的知识；“待审”是尚未应用的提案。三者通过视角和上下文衔接，不得以相同节点标识或线型合并为事实。本体即使没有实例仍可读。探索中的“人物 · 1,234 条”等聚合是实际记录集合，具有独立聚合身份，不是本体类型节点；聚合边数量来自实际关系统计，不是允许的连接规则。

| 图层 | 节点与关系的含义 | 视觉与操作约束 |
| --- | --- | --- |
| 类型定义 | 人物、事件等类型；运行契约允许的关系与属性 | 采用区别于实例的形状或外框，并写“类型定义”；关系写明允许连接。类型颜色和实例保持一致。 |
| 已保存 | 当前空间有效实体和两端都可见的实际关系 | 实体采用稳定实线外框；关系显示可读名、方向和“已保存”身份。选中后能核对依据、版本和历史。 |
| 待审 | 待审批次中的候选实体、关系与修改提案 | 采用虚线或独立形状，并写“待审”；候选与已存同 URI 时仍保留独立选择身份。选择任一候选可到对应批次核对和处置。 |

颜色用于区分业务类型，不兼任“已批准 / 错误”的状态。仅用位置靠近或同色不代表两节点有业务关系。类型—实例的连接若展示，须标为“属于类型”；不是原知识库里的事实关系。同类型边、自环、反向边、多条不同关系和候选间连线不能因布局被误合并。

| 类型 | 面向用户的解释 | 关键内容示例（合成） |
| --- | --- | --- |
| 人物 Person | 人及其身份或别名 | “示例用户” |
| 事件 Event | 有时间线索的经历或活动 | “读书会”，日期及时间精度 |
| 偏好 Preference | 持续偏好及适用条件 | “饮品：无糖茶” |
| 决策 Decision | 已作出的决定及背景 | “选择周末上午学习” |
| 地点 Location | 地点及描述 | “示例图书馆” |
| 概念 Concept | 其他受支持的抽象主题 | “学习计划” |

当前运行契约包含六类实体、九种规范关系：认识、参与、拥有偏好、作出决定、位于，以及通用关联、因果、相关、同一实体。界面从共享契约取得定义和约束，不在前端复制一份可独立漂移的名单。通用关系不能被文案解释成自动证明的因果或真实身份合并。

类型详情包括名称、简明解释、必要字段、允许的出入关系和当前范围内实例数；技术标识在“技术信息”内展开。关系定义包括可读名、方向、起点/终点类型、简短解释和技术标识。运行时校验规则是操作能力的依据；若声明式本体与运行约束不同，应呈现实际支持范围并记录差异，不能把宽泛声明转换为可写权限。

已保存图层的默认范围为“当前命名空间中的有效业务实体”，图中事实边的两端都必须在该范围。归档查询和获准的外部共享只读详情通过同工作区的列表/详情继续访问，不混入当前图的有效实体数。系统回执、审阅批次、历史版本、索引分块、工作空间元数据及隔离记录不伪装成六类业务实体；审阅批次仅作为候选的来源与操作上下文。

定义数、当前范围实体总数、命中总数、已加载节点数、实际边数与候选数量分别命名。过滤和可见性在取候选/分页前生效；计数失败显示未知而不是 0。有限画布使用明确的节点/边上限与截断标记，服务端范围检索必须能找到初始画布之外的记录。界面不得通过把未加载、被隐藏和范围不可见混成一种状态来推断“没有关系”。

### 5.3 交互规则

1. **视角和语义。** 本体显示允许的规则，探索显示事实或事实聚合，审阅显示提案与核对上下文。切换视角恢复各自状态；不能把聚合计数、候选和定义混为事实。业务类型色保持一致，身份另外使用形状、边框和文字。
2. **搜索与筛选。** 搜索可发现全范围目标，不只检索当前画布；定位命中与“仅显示匹配”分开。本体和探索共用有效概念/关系目录，探索默认展开，显示中文说明及全空间有效数量，支持全选与清空；未知数量不显示为零。已存与候选分别采用认证的服务端范围查询，本体在完整定义中搜索。类型和关系筛选有明确当前态；时间筛选若基于已加载预览，必须说明边界，未知日期可独立保留，不能宣称全库时间查询。
3. **单击、双击和拖动。** 悬停只临时强调；单击选择并更新检查器，不自动重排或改变范围；双击聚合节点钻取，双击实体执行明确的关联探索。空白拖动平移，节点拖动移动局部布局；超过移动阈值后不再作为点击。关系布局根据真实连接和共享邻居自动聚集，弱化高连接枢纽；拖动时相关邻域有限收敛，固定节点不动，相机保持稳定，整个拖动及收敛可一次撤销。已有保存坐标保持，可显式重新聚集。减少动态效果偏好、隐藏页面及卸载会停止动画。多选、框选及其替代按钮必须可发现，拖动不触发知识写入。
4. **观察尺度与数据层级。** 滚轮、双指、放大/缩小只改变相机和标签密度；不因越过缩放阈值自动请求数据或展开集合。钻取、扩展、聚焦均由显式操作触发，并保留范围说明和返回入口。
5. **选择、聚焦和扩展。** 选择不改变查询；聚焦以所选实体为新探索范围，返回能恢复之前筛选与相机。扩展邻居可选入向、出向、双向与关系类型，按 distinct 邻居分页；追加页保留已有节点位置，重复展开不产生重复身份。收起仅撤回该次扩展，不能移除仍被其他扩展、固定对象或路径需要的节点。
6. **关系与路径。** 边可选择并显示实际方向、端点与预览；平行边、反向边、自环保持可区分。设置起点和终点后，可查六跳内最短路径或共同邻居。范围、方向、关系过滤、返回上限、读预算和超时必须可见；只在本次搜索范围内说明未找到，不推断现实不存在关联。共同出邻居是 `起点 → 共同节点 ← 终点`，不能画成两条顺向事实。
7. **空间记忆。** 布局提供关系、方向、类型及中心等任务视角；切换布局、筛选、打开检查器、刷新和审阅完成不应无解释地重置相机。固定、隐藏、临时分组、聚光和局部坐标只整理当前视图。首次进入新范围或显式“适配”才整体 fit；位置、距离和线宽不暗示置信度。
8. **撤销与导航。** 可撤销的视图操作和探索前进/后退保存查询、筛选、选择、相机及局部布局，连续拖动合并为一次动作。悬停不进入历史；文本输入框的撤销仍属于文本编辑。画布撤销不撤回已保存更正或批准/拒绝，写入只能使用真实业务补偿能力。
9. **审阅稳定性。** 以批次为核对和写入边界；同 URI 候选与事实独立，能对照内容、依据与关系。提交中防重复、冲突保留草稿，只有服务确认 applied 才显示事实变化；处理后保持当前批次及明确回执，由“下一项”继续，不自动跳到另一个批次。后台刷新不覆盖正在编辑的输入。
10. **失败与恢复。** 局部加载失败保留已读取上下文并标明时点；旧请求不能覆盖新作用域。统计不可用时显示未知和部分图，不把样本称为全图；超时与无路径分开。清除搜索、退出聚焦、恢复筛选与重置画布分别说明影响。
11. **文字替代与命令。** 等价列表共用查询、选择和唯一检查器；工具栏、上下文菜单、键盘与命令入口指向相同动作。节点标签随缩放渐进呈现，完整名称在选择、列表或详情可读，不依赖持续悬停。快捷键只在适用上下文生效，不抢占输入、组合输入或模态编辑。

### 5.4 当前范围与后续演进

v3 默认尽量展示全图。当前范围在 **200 个原始实体、500 条实际关系以内**，且完整统计与返回集合一致时，显示全部原始节点和边；节点或边任一超预算时，显示覆盖该范围全部记录的类型聚合图，再由显式钻取进入实例或局部探索。孤立节点计入覆盖范围。统计未知、节点/边集合截断、客户端可见性裁剪或局部扩展均不得标“全量实体图”；名称/描述的预览截断另行说明，不等同于漏加载实体。预算是可读性与响应边界，不是知识库容量上限。

原有六类实体、九种规范关系与现有属性保留兼容存储身份，当前空间支持版本化定义编辑及个人预制扩展。个人预制复用固定版本公开本体，检查器可查看只读语义来源、标准 URI、版本及映射说明；旧空间显式安装，旧 Concept 不自动重分类，推导结论不作为已保存事实。通用关系的“任意业务类型”不展开成虚构业务事实。审阅沿用每页 20 批、投影至多 60 个候选或待核对端点的受控呈现，完整批次通过已有详情读取。归档、共享只读和语义检索仍在原有范围中，不加入有效图统计。详见[个人本体说明](personal-ontology.md)及[验收记录](personal-ontology-validation.md)。

图预览把名称限制为 240 字符、描述 1,200 字符；事件的 `hermes_eventTime` 和 `hermes_timePrecision` 通过有界字符串投影提供，供已加载图的时间筛选使用，未知时间保持可辨。关系每类来源列表最多保留八项预览，受限时标明不完整。完整实体属性、关系与依据通过认证详情按需读取；这些预览限制用于控制传输和可读性，不改变已保存数据，也不是整库容量承诺。

路径在当前空间的全部有效节点上进行有界搜索，不只检查当前画布；每次最多六跳、五条结果，最多处理 5,000 条关系记录及 2,000 个访问节点。分页/截断检测允许额外 lookahead 记录；最短路径最多额外一条，共同邻居两侧各最多额外一条。生产读取将剩余五秒预算传给 Neo4j 只读事务，并在读前后检查截止时间；连接建立及网络不是严格五秒端到端 SLA。实际限制、超时与未发现路径分开报告。

本体写入只通过 5.6 的显式预览/发布；本次不引入业务图形改边、跨空间路径、服务端持久布局或外部图形上传。临时整理与会话状态不修改事实；大库性能、跨浏览器、真实触控与辅助技术需独立证据，不能由受控读取上限替代。

### 5.5 读取 API 契约

图查询一律为认证的同源 `POST`，私人查询和 URI 置于 JSON 正文；不接受 namespace 覆盖。新请求模型严格校验类型并拒绝额外字段。所有端点限制当前命名空间的有效业务实体，并排除归档/停用、隔离、旧别名、未解决旧记录和其他空间；关系两端及路径中间节点逐一满足范围条件，`shared=true` 不扩大这些图接口的范围。

| 接口 | 请求与默认值 | 响应和关键语义 |
| --- | --- | --- |
| `POST /api/v1/graph/query` | `q=''`（≤200 字符）、`types=[]`（≤6）、新增兼容字段 `relation_types=[]`（≤9）；原 `focus_uri`、`node_limit=120`（1–200）、`edge_limit=240`（1–500）保持兼容 | `GraphSnapshot`：节点、边、总数、截断、`edge_scope='returned_nodes'`、`focus_found`。无聚焦时关系筛选只过滤边；聚焦时同时限制可达邻居。此接口自身仍是有界原始图读取。 |
| `POST /api/v1/graph/overview/query` | `q=''`、`types=[]`、`relation_types=[]` | `{namespace,scope,stats_available,stats_error,total_nodes,total_edges,groups:[{type,count}],relations:[{source_type,target_type,relation_type,count}]}`。统计覆盖全部匹配有效节点；边的两端都满足 q/type，关系筛选不删除孤立节点。计数失败返回 `stats_available=false`、totals 为 `null`、集合为空，仅返回脱敏错误类别。 |
| `POST /api/v1/graph/neighbors/query` | `center_uri` 必填；`direction='both'`（in/out/both）、`relation_types=[]`、`cursor=null`、`limit=30`（1–100） | `GraphSnapshot` 加 `{center_uri,total_neighbors,next_cursor,has_more,relation_counts:[{relation_type,direction,count}]}`。以 distinct 邻居 URI 稳定分页，游标绑定中心、方向和关系范围；客户端原样回传。`total_nodes=全部匹配邻居数+中心`，`total_edges` 只统计中心与本页端点之间符合方向的真实边，最多返回 500 条。 |
| `POST /api/v1/graph/paths/query` | 必填 `source_uri,target_uri`；`mode='shortest'`（或 common_neighbors）、`relation_types=[]`、`direction='both'`（out/both）、`max_hops=6`（1–6）、`limit=5`（1–5） | `GraphSnapshot` 加 `{paths:[{node_uris,edge_ids}],max_hops,truncated,timed_out}`。路径使用真实边的稳定不透明 ID；返回总数只描述本次显示子图。超出读取/结果预算标 `truncated`，数据库/截止时间超时另标 `timed_out`。无路径、范围不可见与超时不能共享同一成功文案。 |

邻居自环不算 distinct 邻居，但作为中心真实边返回；both 下自环分别计入 in/out 的关系计数。关系计数覆盖完整邻域，不只本页。关系输入沿用规范名与既有别名映射；默认不限关系时，未映射的历史关系保留真实 stored type，不伪造本体定义。外空间和不存在/不可见的路径端点统一返回空图，不提供是否真实存在的探针。

HTTP 形状错误为 422，支持范围等业务参数错误为 400，未认证 401，拒绝跨站 403，一般数据库故障 503；统计失败和可辨的路径超时按上表返回结构化读取状态。图查询不触发外部模型、索引构建或知识写入。

### 5.6 本体检查器内编辑与发布

本体默认保持阅读状态。选择类型或关系后进入当前检查器的编辑模式；属性编辑从属性条目进入。名称、说明和安全别名可以编辑，技术 key、IRI、存储标签/关系类型及系统维护属性保持受保护。允许的字段及值域来自服务端 `editing` 能力声明；旧服务、只读适配器或无版本信息时不展示可发布入口。

编辑草稿以进入时的 namespace 和本体版本为基线，后台读取不覆盖输入。离开或关闭时，对改动明确提供继续编辑/放弃；提交进行中锁定上下文。令牌失效保留本标签内草稿，并提供重新连接。草稿不写入 URL、命名视图或浏览器持久存储。发布成功原位更新定义标签与检查器，保留选择 key、坐标、镜头、布局和历史；本体发布不加入画布撤销栈。

内置规则编辑保留运行时最低要求，可增加必填、限制兼容值域、属性适用类型或关系端点；自己新增的限制可在服务声明的范围内撤回。自定义定义按其服务能力编辑，发布后的身份保持固定。预览返回变化字段、已检查的有效记录数量和违规计数；有违规、统计检查失败或规则不兼容时不能发布，不自动改写事实。发布在命名空间写锁内重新检查版本和当前数据，防止预览后新增记录使约束过期。保存的约束用于后续实体写入、修正、审阅批准及归档恢复；不是仅修改图上文字。

| 接口 | 契约与保护 |
| --- | --- |
| `GET /api/v1/ontology` | 原定义/统计加 `version`、`editing` 能力及各定义 `customized_fields`、`custom`、`active`、`allowed_actions`；覆盖层按数据库中的当前 namespace 保存，不修改插件自带 RDF 文件或全局 schema 常量。 |
| `POST /api/v1/ontology/validate` | `{expected_namespace,expected_version,patch,operations?}`；operations 承载新建、停用、恢复和删除；patch 按 `entity_types/properties/relations` 和固定 key 提供改动。namespace 只作当前空间恒等断言，不能选择外空间。返回 `can_publish`、`structural`、变化字段、完整引用影响、风险等级与有效草案；高风险确认凭据绑定此次预览。 |
| `POST /api/v1/ontology/publish` | 同验证请求加 `operation_id` 和可选 `reason`；高风险另带 `confirmation`、`confirmation_token`；严格字段校验、版本比较、发布时重新校验与幂等回执。成功返回版本及生效 schema；409 保留草稿，读取新基线后显式重核对，不静默覆盖。 |

关系覆盖约束作用于当前空间有效端点之间的事实；外部共享端点仍受原内置规则保护，不声称被本空间完整扫描。系统节点保存版本与回执，业务图中不生成本体管理事实节点。备份覆盖层与版本回执应随命名空间一同保存，旧无覆盖层的备份保持兼容。实现与实测边界见[本体编辑验收](ontology-editing-validation.md)。

### 5.7 本体 CRUD：按风险选择提交交互

本体视角提供“管理本体”入口，目录统一管理类型、属性与关系，支持名称/标识搜索和已启用/已停用筛选。主画布仍服务知识探索；定义管理和单定义编辑在检查器内完成。创建成功后保留回执及上下文，新定义以稳定身份加入目录和图；纯元数据更新不触发自动布局或适应全图。

服务端返回 `low / medium / high` 风险等级、动作能力与完整引用统计，界面据此选择提交交互：

| 风险 | 使用方式 | 交互要求 |
| --- | --- | --- |
| 低 | 名称、说明修改 | 预览变化后明确发布；不叠加无必要的确认。 |
| 中 | 所有定义创建、属性约束、别名、关系端点或恢复启用 | 并列解释前后规则、既有记录与候选受影响情况，再发布；旧预览不可用于变化后的草稿。 |
| 高 | 停用、删除及服务判定的其他高影响动作 | 显示对象名称、规范身份、当前/归档事实、待审和定义引用；输入此次动作的确认词，随版本绑定的确认凭据一并提交。 |
| 阻断 | 引用未知、版本/空间不符、约束违例或不允许删除 | 明确原因和下一步，禁止提交；确认不能覆盖阻断。 |

停用与删除必须分别解释：停用阻止新增使用，定义与既有事实仍可核对并可恢复；删除永久移除无引用的自定义定义，不级联删除事实。内置定义不开放删除，有任何当前、归档、候选、历史修订或规则引用的自定义定义不能删除，优先提供“保留历史，改为停用”。统计范围是当前 namespace 的完整拥有数据，包含共享外部目标关系，不能用已加载画布数量替代。

停用定义保留在本体图、管理目录和历史实例读取中，用“已停用”文字及虚线共同区分。动态类型名称从有效本体读取，贯穿端点、目录和实例；它不能被转换为“未分类”或另一种内置类型。旧服务缺少 CRUD 能力时只显示其明确支持的动作。完整验收矩阵与实际执行状态见 [本体 CRUD 验收](ontology-crud-validation.md)。

## 7. 响应式、键盘与辅助技术

### 布局规则

| 范围 | 导航与内容 | 详情与图形 |
| --- | --- | --- |
| ≥1200 CSS px | 约 224 px 侧栏；主区留约 32 px 边距；搜索、图层、类型与范围集中在画布工具区，按内容允许换行。 | 图与唯一上下文详情并列；无选择时优先画布，不常驻第二套完整卡片或表格。 |
| 768–1199 CSS px | 24 px 边距；类型/图层筛选可分组折叠，名称保持可达，不全部挤成无标签图标。 | 空间不足时详情在同页单列展开；选择后滚入并聚焦，提供“返回图谱”。 |
| <768 CSS px | 顶部一级导航保留图标和文字；16 px 边距；搜索、图层、类型和图/列表入口仍可达，操作目标至少 44 px。 | 图与可读列表均可显式选择；图具备缩放/适应按钮；详情单列且始终有返回，长端点名称可换行。 |

断点是起始值，最终按内容和缩放行为验收。避免整页双向滚动。移动端保留同等找回、核对和纠正能力；长批量维护可折叠，不通过隐藏关键功能来达成简洁。

### 键盘和朗读约定

- 页面有“跳到主要内容”；主导航、主区、搜索区具备地标和名称；每页一个主标题。
- `Tab` / `Shift+Tab` 顺序与视觉阅读顺序一致；用原生按钮、输入框、列表和表格，禁止用可点 `div` 模拟全部控件。
- `Ctrl+K`（Windows/Linux）或 `⌘K`（macOS）聚焦当前搜索；有可发现的按钮替代；不在输入、组合输入或模态编辑过程中抢走焦点。`Enter` 提交，不在每个汉字组合阶段请求。
- 若实现标准 tablist，采用方向键和 `Home/End` 切换；若只是筛选按钮则保留普通按钮语义，不假装成标签页。分页按钮朗读名称含方向，并报告新页结果数。
- 常驻上下文详情不伪装成模态，选择结果有可感知反馈，提供可发现的跳转到详情/回图入口；不在每次点击后意外抢走用户焦点。若空间不足采用模态，打开后焦点到标题或合适控件、背景不可交互；`Escape` 关闭并回到原触发项。编辑未提交时提供“继续编辑 / 放弃更改”；原项消失时焦点回到结果标题。
- 图形有简短摘要和文字关系替代；装饰 SVG 对辅助技术隐藏。交互节点/边有可读名称，包含图层身份、类型/关系名与端点；缩放、聚焦、退出聚焦和适应有按钮替代，不仅支持捏合或拖拽。大量节点不要求用户逐一 Tab 穿过才到关键操作，列表路径保持可用。
- 查询结束、页码和任务状态用礼貌状态消息；错误使用及时但不重复播报的提示。重渲染不反复朗读整页，不把焦点自动移到轻量通知。
- 触控和粗指针操作目标采用至少 44×44 CSS px 的项目标准；桌面紧凑图标按钮允许 36×36 CSS px，保留间距并逐项核对 WCAG 目标尺寸要求。焦点轮廓为 3 px 高对比绿色，加至少 2 px 间隔；高对比模式仍可识别。这里的 44 px 是项目选择，不是 Apple 官方认证或全部 WCAG 条款的替代。

| 首次加载 | 保留标题/筛选，显示稳定骨架或“正在读取类型定义”。 | 不显示闪烁的 0；无真实比例时不用进度条百分比。 |
| 切换筛选 | 控件立即显示所选项，结果区标注更新中；旧结果若保留须降低视觉强调并写“正在更新”。 | 取消/忽略旧请求；不把旧类型结果留在新标题下。 |
| 无任何实例 | “当前范围还没有已保存的记忆”；类型与关系定义仍可读。 | 到同步状态/审阅的入口；无自动外发、自动抽取按钮。 |
| 搜索无结果 | “没有匹配的记录。可尝试更短关键词或调整范围。” | 保留原词，提供清除筛选；说明无结果不证明从未记录。 |
| 某类型为零 | “此类型暂时没有有效记忆”；说明当前空间和有效数据范围。 | 可在同工作区列表查归档；不删除类型定义。 |
| 图无边或截断 | 区分“全量实体图”“全库聚合”“已加载局部/部分图”；写明当前范围及已读取数量。 | 全量统计超过预算切聚合，统计失败明确未知；有选择/隐藏裁剪时不声称全量原始图。 |
| 路径无结果 | “在当前方向、关系类型和六跳范围内未找到路径”。 | 只有搜索完整结束才作该范围说明；允许调整条件，不能推断全库或现实无关联。 |
| 路径预算或超时 | “搜索达到读取预算，结果可能不完整”或“路径查询超时”。 | 保留端点和原画布，提供缩小条件/重试；不将二者显示为确定无路径。 |
| 全部类型或图层隐藏 | “当前没有显示的类型/图层”。 | 保留开关，提供恢复默认；不写成“知识库为空”。 |
| 选择因筛选不可见 | 清除已无效选择/聚焦，或标注“当前筛选隐藏了所选节点”。 | 有单步恢复入口；不把旧详情留在新图下当成当前事实。 |
| 候选与原实体同标识 | 分别显示“待审提案”和“已保存版本”，可在同一审阅上下文核对。 | 批准前不覆盖事实；拒绝/延后不显示成已应用。 |
| 局部失败 | “类型定义已读取，实例暂时无法获取”。 | 单独重试失败区；成功部分继续可用，数量标未知。 |
| 服务失连 | 页内横幅“连接已中断，正在显示上次读取的内容”，标最后更新时间。 | 重连按钮；禁用写入并说明原因；不抹掉草稿。 |
| 认证失效 | “连接凭证已失效，请重新连接”。 | 清除失效认证；不展示原凭证；重新连接后恢复安全的浏览位置。 |
| 记录已变化 | “这条记忆已被更新。请核对最新版本后再保存。” | 保留本次输入，提供看新版本/继续处理；不静默覆盖。 |
| 记录不可见/消失 | “此记录当前不可查看，可能已归档或不在当前范围”。 | 返回列表并刷新；避免泄漏真实隐藏原因和对方内容。 |
| 写入进行中 | 按钮“正在保存”，相同操作不可重复提交。 | 成功后显示新版本/状态；失败仍留输入。 |
| 长任务 | “已加入队列 → 正在处理 → 完成 / 部分失败”，可查看详情。 | 退出页面不取消任务；取消是否可用以实际后端能力为准。 |
| 模型/索引不足 | “当前使用关键词检索；本地语义索引尚未就绪”。 | 到准备/索引页面；不会在搜索时自动下载模型。 |

可撤销的操作优先提供恢复路径。当前归档/恢复属于服务端持久操作，须写清影响；不要因为网络超时宣称操作必然未发生。不可逆删除若未来加入，需专门列明对象、范围及恢复边界，不沿用轻量“成功”通知。

## 9. 设计系统与内容规范

### 9.1 语义 token（目标值）

这是收敛现有样式的实施规格，不表示当前 CSS 已全部采用。由一套 token 控制页面、抽屉、图表和状态，减少不断追加局部覆盖规则。

| token / 类别 | 初始值 | 用途与约束 |
| --- | --- | --- |
| `color.canvas` / `surface` / `surface.subtle` | `#F7F8F5` / `#FFFFFF` / `#F2F5EF` | 对应页面背景、`--paper`、`--soft`；内容以边界/留白区分，少用重阴影。 |
| `color.text` / `text.secondary` | `#22332B` / `#58675F` | 对应 `--ink` / `--muted`；白底对比分别约 13.32:1 / 5.97:1；次要不等于难读。 |
| `color.action` | `#315C45` | 对应 `--green`；白字约 7.64:1；同屏主行动保持克制。 |
| `color.success` / `warning` / `danger` / `info` | `#2F694B` / `#825A15` / `#A13D35` / `#255E91` | 白底文字对比分别约 6.48 / 6.14 / 6.49 / 6.80；必须配文字/图标。 |
| `color.focus` / `border.control` / `border.decorative` | `#315C45` / `#829088` / `#DCE3DC` | 焦点白底约 7.64:1，功能边界约 3.34:1；`--line` 仅用作装饰分隔，不单独表示输入框或选中态。 |
| 字体 | `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` | 使用设备字体；不从外部字体站发送浏览请求。代码标识用系统等宽栈。 |
| 字号与行高 | 页标题 28/36；区域标题 20/28；主内容至少 14 px、行高 1.65–1.8；辅助至少 12 px | 当前共享 CSS 使用 `px` 及部分 `rem`；统一相对单位是后续治理目标。本次验证浏览器缩放与重排，不宣称已完整支持自定义文字缩放。长证据/阅读段落可用 16 px，名称和证据允许换行。 |
| 字重 | 400 / 500 / 600 | 正文、控件、层级；不用极细字重承载低对比辅助信息。 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 px | 分别用于细间隔、控件组、内容区与区域分隔；同类间距一致。 |
| 圆角 | 8 px 控件；12 px 卡片；16 px 大型弹层 | 支持温和、清楚的边界，不把每一行都做浮起卡片。 |
| 动效 | 120–180 ms 轻过渡；200 ms 抽屉 | `prefers-reduced-motion` 下去除位移/自动布局动画；不让背景持续运动。 |
| 图形 | 18–20 px 控件图标；24 px 区域图标；线宽一致 | 图标只辅助文字；类型名称不因空间不足永久隐藏。 |

表中对比为纯色白底计算值；实际状态、透明度、选中背景和暗色模式需重新测量。暗色主题为 P1，需单独定义语义色和测试，不用全页反色实现。类型可用低饱和色点缀，但“人物=蓝色”等不是唯一编码；状态色不兼任类型含义。

### 9.2 文案与可信度

- 先说人需要知道的事：“已保存新版本”“本次查询使用关键词检索”；详情再解释技术原因。
- “类型定义 / 已保存 / 待审”“已应用 / 延后 / 已拒绝”“排队 / 运行 / 完成”使用固定词汇。图层、关系线和检查器同时表明身份，不仅靠颜色提示。
- 不使用“绝对准确”“已理解你”“全部记忆”等超出证据的表达。时间未知、日期精度不足、来源缺失和模型推断均明确标识。
- 原始关系名、URI、模型标识等放到可展开技术信息，并有复制按钮；复制成功不抢焦点。个人路径、令牌及连接串不作为默认诊断内容。
- 错误按“发生什么 → 对当前操作的影响 → 下一步”写；禁止把异常堆栈直接作为用户说明。
- 仅显示确实可执行的恢复动作。暂停抽取不称为断开数据；断开浏览器不称为停止服务。

## 10. 评估与实施计划

### 10.1 分阶段交付

| 阶段 | 范围 | 放行依据 |
| --- | --- | --- |
| v3-A 语义与全图基础 | 本体/探索/审阅视角；浅色画布与唯一检查器；完整统计；200/500 内全量原始图、超预算类型聚合与显式钻取。 | 本体/聚合/事实身份不混淆；孤立节点和边预算验证；统计失败不伪造 0。后端已取得自动及真实 Cypher 证据，界面状态另验。 |
| v3-B 画布交互体系 | 选择/多选/框选、拖动、缩放、布局、固定/隐藏、临时分组、聚光、小地图、菜单/命令入口、文字替代与视图历史。 | 手势不冲突，选中不重排，扩展不漂移；撤销与输入编辑、业务写入分离。须有真实浏览器任务及键盘证据。 |
| v3-C 发现与分析 | 全范围搜索定位与过滤分离；按方向/关系分页扩展、收起；受控最短路径和共同邻居；时间筛选说明范围。 | 图外命中、稳定分页、真实边方向、共享中间节点、预算/超时/无结果分辨、旧请求不覆盖新状态。 |
| v3-D 审阅与可靠性 | 批次上下文、候选/事实对照、版本/幂等复用、回执后稳定位置、显式下一项；集成与故障回归。 | 成功/冲突/故障保留正确状态；不自动跳批次、不制造事实；浏览器、辅助技术及性能结论逐项记录。 |
| 后续演进 | 大库生命周期列表服务端分页、参考性能基准、暗色主题、脱敏故障摘要；经研究再考虑本体写入、跨空间、团队协作和持久布局。 | 不将当前有界查询或浅色主题当作其他能力的完成；权限、版本与迁移独立评审。 |

v3-A～D 是同一交互体系的实施与验收分组，不表示只交付第一阶段或默认取消高级交互。完成度按 [v3 验证记录](graph-v3-validation.md) 中的证据判定；代码存在、单测通过、浏览器代表路径、性能和辅助技术是不同层次，不能互相替代。

### 10.2 用户研究与任务测试

先访谈约 5–8 位目标知识所有者及 2–3 位维护情境使用者，使用合成数据或参与者自行选择的低敏内容。研究不要求上传个人对话。重点验证类型/实例心智模型、信任判断、维护频率、移动场景与术语理解。记录反证并修改 persona；这个样本用于形成设计，不作市场统计推断。

随后进行两轮形成性可用性测试，每轮约 5–6 人，覆盖首次使用和复访。任务包括：用改写查找一条偏好；聚焦人物并找出相关事件；解释类型定义边、实际关系和待审候选的区别；通过列表完成等价任务；核对来源并修正错误；处理保存冲突；批准或拒绝候选并解释终态；在索引未就绪时解释结果；在手机上返回原筛选位置。

初始设计目标：关键任务无帮助完成率 ≥85%；基础定位中位时间 ≤60 秒；至少 80% 参与者能正确区分定义、已存与候选；“把候选或排队认作已保存”“把无结果或截断认作没有知识”“不知情外发”三类严重理解错误为 0。达不到目标时报告样本、任务和原因，不将小样本结果包装成总体保证。

### 10.3 工程与无障碍验收矩阵

| 维度 | 必测情境 | 记录证据 |
| --- | --- | --- |
| 数据 | 零数据、六类、零实例定义、超过图上限、别名、归档、共享只读、隔离/系统节点、不可见端点、同 URI 候选、自环/反向/多关系 | 合成夹具、期望计数、接口响应和截图；不复制生产数据入仓库。 |
| 一致性 | 快速切类型/图层、慢请求乱序、图外搜索命中、聚焦图外邻居、审阅终态、图/列表切换、选择被隐藏、详情返回、前进/后退 | 旧响应不覆盖、候选不变伪事实、范围和计数一致、上下文保留。 |
| 故障 | 401、403、404、409、服务中断、超时、局部失败、模型/索引未就绪、任务失败 | 每种状态的文案、焦点、草稿保留和恢复行为。 |
| 可访问性 | 全键盘；Windows NVDA + Chromium；macOS VoiceOver + Safari；适用时补移动屏幕阅读器 | 完整任务录像/记录；自动扫描结果及人工缺陷单。工具可用性限制如实记录。 |
| 视觉与重排 | 320/390/768/1280/1920 CSS px，200% 文字、400% 浏览器缩放，高对比，减少动态效果 | 标题/按钮/图例不遮挡，主要任务无整页横滚，图有文字替代。 |
| 隐私与安全 | URL/历史、控制台/错误、恶意标签文本、共享范围、外部网络请求 | 无凭证或个人数据泄漏，HTML 不执行，模型开关关闭时无外部解释请求。 |
| 性能 | 受控合成规模、冷/热缓存、模型冷启动、大量关系 | p50/p95、设备和样本数；不把本地一次快速加载当作容量保证。 |

发布评审应附上“已验收 / 未验收 / 已知限制”的清单。当前文档是可执行设计基线；完成代码、构建或后端测试只能覆盖其中一部分，不能据此宣称 UI/UX、全部设备或所有 Agent 已验证。
