# 本体 CRUD 风险与验收

当前工作覆盖自定义实体类型、属性、关系的创建、查看、修改、停用、恢复与受约束删除。具体服务能力、允许动作和风险等级由后端返回；界面不能把“可编辑”推断为“可删除”。内置定义身份保持稳定，历史事实和审计记录不因定义停用而消失。

## 风险分级与交互

| 等级 | 典型动作 | 必须展示的信息 | 提交交互 |
| --- | --- | --- | --- |
| 低 `low` | 名称/说明修改 | 定义身份、变化字段、作用 namespace、受影响数量 | 预览后明确发布；不为每个低风险字段添加额外确认。 |
| 中 `medium` | 所有定义创建；属性值型/必填/适用范围、关系端点、别名改变；启用自定义定义 | 新旧规则、当前有效与归档引用、待审候选、其他定义引用，以及对后续写入的影响 | 通过服务端兼容预览后发布；修改草稿使预览失效，版本冲突必须重新核对。 |
| 高 `high` | 停用、删除定义，或服务判定的其他高影响动作 | 对象名称和规范身份、完整空间引用统计、历史读取与新写入的区别；删除时说明不可直接恢复定义及可替代的停用动作 | 独立确认具体动作，再发布；确认不能覆盖服务端阻断。 |
| 阻断状态 | 统计未知；版本/空间不符；规则违例；删除内置定义或有引用定义 | 明确原因、未知值和可执行下一步 | 禁止提交，不把未知统计当作零，也不提供强制绕过。 |

风险是服务端结果；上述典型动作帮助解释，不代替实时计算。新增定义的 key、IRI 和存储映射先校验再预览，发布后不提供原地改身份的假编辑。删除仅允许自定义且无任何服务定义引用的对象。引用统计以当前 namespace 的完整拥有数据为范围，包含归档事实、指向共享外部目标的本空间关系、待审候选、历史修订和其他定义的规则引用；它不是当前画布加载数。

## 呈现与兼容边界

- `active=false` 是定义停用，不能冒充实体归档。停用定义仍在本体图与管理目录中可查，并用文字和虚线共同标记；关联历史事实仍可读取。
- 自定义类型键贯穿读取、候选、图节点、目录筛选和实例查询，不得在前端被转换为 `unknown` 或 `concept`。未知服务类型可以安全回退图标和颜色，身份仍保留。
- 名称来自有效本体；内置中文回退仅在没有自定义显示值时使用。端点范围和属性适用类型也显示自定义类型名称。
- 默认全类型范围随新定义扩展；用户明确选定的子集保持原意。删除后的旧筛选和命名视图应提示失效定义，避免发送失效键或静默换成其他类型。
- 老服务缺少生命周期字段时按有效定义展示；缺少 CRUD 能力时继续只读或使用其已声明的更新能力，不出现无效的创建/删除按钮。
- 定义变化沿用稳定的 `schema:<key>` 身份；元数据发布不重排、不 fit，不清空镜头与选择。真正删除选中定义时明确清理失效选择，保留其余画布上下文。

- **CRUD-01 / 02 / 08：** 实际发布自定义类型、整数/日期属性及关系，再写入并读取卡片、目录、provider、混合检索、本体统计、图、邻居和路径；类型身份保持，业务属性值可检索。非法存储身份、跨 namespace 未定义使用与额外字段被拒绝。
- **CRUD-04：** 低/中/高风险分类、发布时重算引用、确认词及绑定版本/请求/引用计数的 token 均有回归。预览后新增引用拒绝旧确认；统计故障返回脱敏 503，未发布且不把未知当零。
- **CRUD-05：** 停用类型保留历史读取和已有记录更正，拒绝新实体及新关系对停用类型的使用。停用属性可原样保留，拒绝新值；恢复后可重新写入。创建/恢复定义显式依赖停用类型时阻断，内建底线仍有效。
- **CRUD-06 / 07：** 空且无依赖的自定义类型/属性可确认删除，系统派生姓名规则不永久阻止空类型删除。内置身份、归档事实、历史修订、待审候选、规则引用和本空间指向外部共享目标的关系均保护硬删，不级联删事实。关系 active/archived 统计包含停用、隔离及别名状态。
- **CRUD-07 候选引用：** 顶层姓名按人物/其他类型分别计入姓名属性；Preference/Decision 默认 owner、Event.agent 的自动关系纳入待审引用。冻结的旧别名语义在移除/重绑后保持，旧无快照批次不被新别名静默重解释。
- **CRUD-10：** 同 namespace 跨 home 回读、版本竞争、历史幂等回执、定义与停用事实备份往返通过；恢复约束冲突整批回滚。三个本体元数据唯一约束实际拒绝重复身份。

历史未注册 `x_*` 字段仅可在同一已有事实中原样保留，新增或改值拒绝；关系须所有匹配旧边都有相同原值，客户端伪造旧值信息不能绕过。日期 driver/native 差异不妨碍保留，停用日期更正后仍保留原有 9 位纳秒，布尔值不与整数混同。已有 datetime 改成 date、datetime 数组当标量均被兼容预览阻断。自定义属性本轮只开放标量，能力返回 `create_value_shapes=['scalar']`。

新增/重绑属性别名扫描当前和归档实体、拥有关系、历史修订、待审字面字段，占用返回 `alias_field_in_use`，不能确认绕过。旧备份若已有歧义别名，不自动迁移事实：无关更正返回明确中文 409，指引先在本体管理撤销冲突兼容名称。实测拒绝后字段、姓名、版本不变；撤销后可安全更正。标签空白统一为单空格并拒绝其他控制字符，确认词可在单行输入框使用。

一次中间运行在隔离实例读取历史引用时出现 Socket 10054 连接重置，服务端根因未确认；未重启现有服务或放宽检查。随后完整重跑未复现，最终 201 项全通过。测试夹具已改用独特业务值，避免单字符数字误命中随机 URI；历史不安全状态用明确旧状态夹具模拟，不借新发布接口绕过保护。provider 单元测试隔离本机 console HTTP，防止绕过模拟数据。

真实数据库用例使用随机合成 namespace、临时 home 并注册清理；最终运行清理均完成，删除自己创建的实体、元数据、外部合成端点并移除临时 home，未读取业务空间、未停止或重启用户服务。`compileall` 与 `git diff --check` 通过。本节不声称真实浏览器和真实数据库完成一体化写入验收，也不补充未测辅助技术或负载证据。
