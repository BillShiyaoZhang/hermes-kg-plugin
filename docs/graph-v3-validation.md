### 万级合成数据库样本

新增可复现脚本 `scripts/benchmark_graph.py`，使用同一隔离开发 Neo4j 和本次调用随机生成的专属 namespace。最终一轮实际创建 **10,000 个有效实体、30,000 条真实关系**：人物、事件、偏好、决策、地点各 1,666 个，概念 1,670 个；独立核对 **100 个孤立节点、30 条自环及一对端点间 1,000 条平行边**。所有边和端点均属于本轮合成空间。

这次直接调用 `OntologyService`，通过 Bolt 执行真实 Cypher；没有经过 HTTP 序列化、浏览器或前端布局。宿主为 Windows x64，Python 3.11.16，CPU 标识 `Intel64 Family 6 Model 151 Stepping 2, GenuineIntel`，20 个逻辑 CPU；数据库为 Docker 中的 Neo4j 5.26 Community。没有采集容器 CPU/内存配额，不能把宿主逻辑 CPU 数等同于容器份额。采用默认十秒读取事务上限；夹具创建耗时 0.760 秒，不计入下表服务读取时间。

最终一轮每个操作连续采样 **3 次**，单位为毫秒。首次样本在刚写入夹具后执行，不是冷缓存测试；查询计划可能已由先前测试预热。列出全部样本及中位数，不计算或宣称稳定 p95、并发吞吐或生产 SLA。

## 前端实现与复现

本轮前端自动测试 **171 项通过**，TypeScript/Vite 生产构建通过。包括本体定义、读取及属性筛选，工作区全图语义/展开所有权/分组/历史，认证 POST 传输，并列核对/命名视图，事件时间分布，审阅差异与写入草稿策略，以及聚合集合的箭头边界和窄屏适应范围。子模块测试是这 171 项的组成部分，不额外叠加计数。

完整工作台脚本 `scripts/graph_v3_browser.cjs` 在生产预览运行：所有 `/api/v1/` 请求均由脚本拦截并返回虚构内容；浏览器审批不会写入真实数据库。API 与真实数据库能力由前述 63 项独立回归验证，不能把两组证据合称“浏览器对生产数据库的写入验收”。脚本输出位于忽略的 `reports/graph-v3/`，包含 JSON、桌面、聚合、窄屏及放大截图。

```powershell
# console/：先构建并启动回环预览
npm test
npm run build
npm run preview -- --port 5175 --strictPort

# 仓库根目录：PLAYWRIGHT_MODULE 指向已有的 Playwright 安装
$env:KG_V3_BROWSER_URL = 'http://127.0.0.1:5175'
# 可选 KG_CHROME_PATH 指定本机 Chrome；未设置则使用 Playwright Chromium
node scripts/graph_v3_browser.cjs
```

同一脚本也是可复现的合成关键流程原型：可选设置 `$env:KG_GRAPH_INTERACTIVE='1'` 后运行，它会打开可见浏览器，验收后恢复小图并保留窗口，直到用户关闭。可体验三视角、搜索、扩展、审阅、保存和导出；所有 API 仍由虚构夹具拦截，不连接真实记忆。默认自动验收分支已实测，可见窗口分支只完成代码检查，未把它计作真实人工可用性研究。

独立画布脚本 `scripts/graph_canvas_browser.cjs` 对 Vite 开发服务器运行，`KG_BROWSER_URL` 指定地址；通过路由提供合成 Canvas 夹具并拒绝任何 API 访问。它验证手势互斥、坐标稳定、同源布局 Worker、CSP 允许范围内的 PNG 和 SVG 导出，并记录性能。

## 性能样本与修正

参考设备：Windows，Intel Core i7-12700，20 逻辑核，64 GB RAM，Chrome 155.0.8059.85 无头模式，1200 × 1000 视口。独立 Canvas 夹具为 300 节点、800 边；每个平移/缩放样本持续约 4 秒、240 次输入，三轮共 6 个样本。镜头基准通过 rAF 调度程序生成的 PointerEvent / WheelEvent，记录持续输入期间的帧，未以空闲帧冒充交互帧；它不等同于物理鼠标或触屏输入。

最终六样本观测 **59.995–60.000 FPS**，帧间隔 p95 **16.8 ms**，DOM 镜头变换响应 p95 **16.8–16.9 ms**。独立执行 **50 次原生浏览器鼠标点击**（Playwright `page.mouse.click`），从浏览器 `pointerdown` 到出现选中 DOM class 后的下一动画帧，测得选择反馈 **p95 67.5 ms、中位数 26.8 ms、最大 208 ms**。首击长样本及所有原始值均保留，未剔除高值。两项均达到本次参考设备上的目标；这不是完整工作台详情网络延迟、所有设备、冷布局或真实触屏性能保证。数据保存在 `reports/graph-v3-canvas/performance.json`。

测试实际暴露并修复：相机逐帧触发整图 React 重绘；父级回显取消下一帧；首次恢复错误使用默认视口尺寸补偿；窄屏节点留在屏外；PNG 使用 blob 中间图被生产 CSP 拦截；普通淡化使标签难以阅读；选择时重建静态图标与边、反复注册 ref 和全图透明度过渡增加停顿。当前相机通过 rAF 更新合成层，手势结束保存镜头；节点/边静态内容 memo、引用回调和事件分发保持稳定；快照携带视口尺寸，布局/镜头历史分开保存；PNG 中间图使用允许的 data URL，不放宽 CSP。
